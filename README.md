# Image viewers


> [*Notes on released versions*](https://github.com/neelsmith/imageviewer/blob/main/releases.md)

Apps for light-table and zoomable/pannable display of individual images, implemented in self-contained HTML files that can be run locally or served on the web. Supports cataloging of images in simple delimited-text files, and filtering of light-table display by cataloged data, or by date and location encoded in the images.

- **1.x** series focuses on serving files hosted on [pCloud](https://www.pcloud.com).
- the project's github pages site hosts an [example installation](https://neelsmith.github.io/imageviewer/catalogs.html)
- `image-viewer.html` is a stand-alone app you can use to browse and catalog images in your local file system
- documentation for `image-viewer.html` is available at [https://neelsmith.github.io/imageviewer/](https://neelsmith.github.io/imageviewer/)
