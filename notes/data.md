# The `data/` directory

All files are pipe-delimited CEX with a header row, served from GitHub raw (`dataBase`).
Image `path`s are relative to the pCloud Public Folder.

| File | Contents |
|---|---|
| `images.cex` | Index of every image: `path\|date\|lat\|lon\|city\|region\|country\|width\|height`. Generated by `utils` (`npm run images-index`), not hand-edited. |
| `catalog.cex` | Main catalog: `path\|caption\|credits\|license\|tags` + optional `year\|place\|urn`. Catalog order = display order. |
| `catalogs/*.cex` | Public catalogs (same format). |
| `catalog_of_catalogs.cex` | `cex_file\|label`: list of public catalogs (paths from repo root). |
| `private/*.cex` | Password-protected catalogs (same format). |
| `catalog_of_private_catalogs.cex` | `cex_file\|label\|password` (PBKDF2 hash, from `utils/catalog-password.mjs`). |
| `last-updated.txt` | A date shown beside the app version (optional). |

## Use by each app

- **catalogs.html**: menu from `catalog_of_catalogs.cex` → chosen `catalogs/*.cex`, joined with
  `images.cex` for dates, places and sizes. Cataloged images only.
- **private.html**: `catalog.cex` + `images.cex`; can show all indexed images (`#all=1`).
- **private-catalogs.html**: menu from `catalog_of_private_catalogs.cex` → chosen `private/*.cex`
  (password per catalog), joined with `images.cex`.
- **www-browse.html**, **local-image-viewer.html**: don't use `data/`. They read `images.cex`,
  `catalogs.cex` and any `.cex` catalogs from the served or opened folder itself.

The first three also read `last-updated.txt`. `#urn=` links search the same catalogs (see `citation.md`).

The slide-show pages (`*-slideshow.html`) read the same files as their apps.
