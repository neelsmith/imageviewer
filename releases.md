# Version info


Current version: **1.6.0**

**1.6.0**,*Oct. 13, 2027*:  apps separately track software version number and last modified date for data.


**1.5.0**,*Oct. 13, 2027*:  adds support for password-protected individual catalogs

**1.4.0**,*Oct. 13, 2027*: 

- adds utility to cull obsolete thumbnails.
- allows optional `year` and `place` columns in catalogs
- allows filtering by `year` and `place` if included in catalog

**1.3.0**, *Oct. 13, 2026*: 

- adds utility to create thumbnails, and uses those for lightbox viewing to cut down on traffic from pCloud.
- makes individual images addressable/bookmarkable by URL


**1.2.0**, *Oct. 13, 2026*: adds +/- zoom on individual images.

**1.1.0**, *Oct. 13, 2026*: private app adds toggle to view all images or only cataloged images.

**1.0.0**, *Oct. 13, 2026*: initial release. Select a catalog of images, browse thumbnails by data, location or tag, see full size images, or link to originals hosted on pCloud.
